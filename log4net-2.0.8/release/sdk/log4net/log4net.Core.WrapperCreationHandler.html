Delegate used to handle creation of new wrappers.

Remarks

Delegate used to handle creation of new wrappers. This delegate is called from the CreateNewWrapperObject(ILogger) method to construct the wrapper for the specified logger.

The delegate to use is supplied to the WrapperMap constructor.
