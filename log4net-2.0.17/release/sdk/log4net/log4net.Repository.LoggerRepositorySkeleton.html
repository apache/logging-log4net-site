Parameters

logEvent LoggingEvent

the event to log

Remarks

This method should not normally be used to log. The ILog interface should be used for routine logging. This interface can be obtained using the log4net.LogManager.GetLogger(string) method.

The logEvent is delivered to the appropriate logger and that logger is then responsible for logging the event.

ResetConfiguration()

Reset the repositories configuration to a default state

public virtual void ResetConfiguration()

Remarks

Reset all values contained in this instance to their default state.

Existing loggers are not removed. They are just reset.

This method should be used sparingly and with care as it will block all logging until it is completed.
