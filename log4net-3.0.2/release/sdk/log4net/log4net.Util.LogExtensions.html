Remarks

This class contains methods for logging at different levels and checks the properties for determining if those logging levels are enabled in the current configuration.

Methods

DebugExt(ILog, Func<object>)

Log a message object with the Debug level.

public static void DebugExt(this ILog logger, Func<object> callback)

Parameters

logger ILog

The logger on which the message is logged.

callback Func<object>

The lambda expression that gets the object to log.

Remarks

This method first checks if this logger is INFO enabled by reading the value IsDebugEnabled property. This check happens always and does not depend on the ILog implementation. If this logger is INFO enabled, then it converts the message object (retrieved by invocation of the provided callback) to a string by invoking the appropriate IObjectRenderer. It then proceeds to call all the registered appenders in this logger and also higher in the hierarchy depending on the value of the additivity flag.

WARNING Note that passing an Exception to this method will print the name of the Exception but no stack trace. To print a stack trace use the DebugExt(ILog, Func<object>, Exception?) form instead.

public static void WarnExt(this ILog logger, object? message, Exception? exception)

Parameters

logger ILog

The logger on which the message is logged.

message object

The message object to log.

exception Exception

The exception to log, including its stack trace.

Remarks

See the WarnExt(ILog, object?) form for more detailed information.

WarnFormatExt(ILog, IFormatProvider, string, params object?[]?)

Logs a formatted message string with the Warn level.

public static void WarnFormatExt(this ILog logger, IFormatProvider provider, string format, params object?[]? args)

Parameters

logger ILog

The logger on which the message is logged.

provider IFormatProvider

An IFormatProvider that supplies culture-specific formatting information

format string

A String containing zero or more format items

args object[]

An Object array containing zero or more objects to format

Remarks

The message is formatted using the String.Format method. See Format(string, params object[]) for details of the syntax of the format string and the behavior of the formatting.

This method does not take an Exception object to include in the log event. To pass an Exception use one of the WarnExt(ILog, object?, Exception?) methods instead.
