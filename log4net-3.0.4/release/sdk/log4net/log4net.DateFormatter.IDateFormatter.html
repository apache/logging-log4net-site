Render a DateTime as a string.

public interface IDateFormatter

Remarks

Interface to abstract the rendering of a DateTime instance into a string.

The FormatDate(DateTime, TextWriter) method is used to render the date to a text writer.

Methods

Formats the specified date as a string.

void FormatDate(DateTime dateToFormat, TextWriter writer)

Parameters

dateToFormat DateTime

The date to format.

writer TextWriter

The writer to write to.

Remarks

Format the DateTime as a string and write it to the TextWriter provided.
