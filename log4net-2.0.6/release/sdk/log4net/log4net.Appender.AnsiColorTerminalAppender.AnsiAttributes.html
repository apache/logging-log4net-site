Blink = 8

text is blinking

Not all terminals support this attribute

Bright = 1

text is bright

Dim = 2

text is dim

Hidden = 32

text is hidden

Light = 128

text color is light

Reverse = 16

text and background colors are reversed

Strikethrough = 64

text is displayed with a strikethrough

Underscore = 4

text is underlined

Remarks
