Remarks

The memory appender stores all the logging events that are appended in an in-memory array.

Use the PopAllEvents() method to get and clear the current list of events that have been appended.

Use the GetEvents() method to get the current list of events that have been appended. Note there is a race-condition when calling GetEvents() and Clear() in pairs, you better use in that case.

Use the Clear() method to clear the current list of events. Note there is a race-condition when calling GetEvents() and Clear() in pairs, you better use in that case.
