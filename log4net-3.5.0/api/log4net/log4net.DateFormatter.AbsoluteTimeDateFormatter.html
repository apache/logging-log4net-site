Remarks

Uses the FormatDateWithoutMillis(DateTime, StringBuilder) method to generate the time string up to the seconds and then appends the current milliseconds. The results from FormatDateWithoutMillis(DateTime, StringBuilder) are cached and FormatDateWithoutMillis(DateTime, StringBuilder) is called at most once per second.

Subclasses should override FormatDateWithoutMillis(DateTime, StringBuilder) rather than FormatDate(DateTime, TextWriter).

FormatDateWithoutMillis(DateTime, StringBuilder)

Renders the date into a string. Format is "HH:mm:ss".

protected virtual void FormatDateWithoutMillis(DateTime dateToFormat, StringBuilder buffer)

Parameters

dateToFormat DateTime

The date to render into a string.

buffer StringBuilder

The string builder to write to.

Remarks

Subclasses should override this method to render the date into a string using a precision up to the second. This method will be called at most once per second and the result will be reused if it is needed again during the same second.
