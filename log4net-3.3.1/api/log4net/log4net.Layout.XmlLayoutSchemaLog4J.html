Remarks

The LocationInfo option takes a boolean value. By default, it is set to false which means there will be no location information output by this layout. If the option is set to true, then the file name and line number of the statement at the origin of the log statement will be output.

If you are embedding this layout within an SMTPAppender then make sure to set the LocationInfo option of that appender as well.
